# Portfolio Website

Developer portfolio website built with Next.js, TypeScript, and Tailwind CSS. Showcasing projects, skills, and professional experience.

## Tech Stack

- **Framework**: Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies: \
pm install\
3. Run development server: \
pm run dev\
